## Projects

### Project 1 — Pulse Smart Water Bottle: Quick Start Guide
**Standard:** DITA  
**Topics:** Four task topics covering unboxing, charging, app pairing, 
and cleaning  
**Demonstrates:** DITA task topic structure, DITA map assembly, 
WebHelp Responsive and PDF publishing

### Project 2 — Tasklytics API: Reference Documentation
**Standard:** DITA  
**Topics:** Concept topics covering API overview and authentication, 
reference topics covering endpoints and error codes  
**Demonstrates:** DITA concept and reference topic types, properties 
tables, code examples, keyref for single-sourced constants

### Project 3 — Aria Mesh Router: Troubleshooting Guide
**Standard:** DITA  
**Topics:** Concept, reference, and troubleshooting topics covering 
mesh networking, LED status indicators, and two fault diagnosis procedures  
**Demonstrates:** DITA troubleshooting topic type with condition, cause, 
and remedy structure; topichead grouping in a map

### Project 4 — NoteForge App: Multi-Edition User Guide
**Standard:** DITA  
**Topics:** Overview, sign-in, create note, and collaboration tasks

**Demonstrates:** conref content reuse across topics, DITAVAL conditional 
publishing to produce multiple deliverables from one source, 
audience-based filtering

### Project 5 — Stratos Compact UAV: System Description
